# 四堂串接：條件與證據

| 關卡 | 檢查 | 缺資料時 |
|---|---|---|
| 策略→選股 | 事件日、當時可知條件、策略版本、歷史母體 | 列候選，不判合格 |
| 籌碼 | 法人與分點的期間、買超量／比例、集中與持續性、價量配合 | 沿用老師定義，未提供門檻標人工判讀 |
| 技術 | 型態名稱、價位、區間、量能、觸發頻率、失效點 | 圖形描述不是自動買進 |
| 商品 | 現股／CB代碼、轉換價、溢價、買賣價差、成交量、發行／賣回期限 | 沒有歷史當時轉換價就不回算歷史溢價 |
| 風險 | 風險預算、單位、計畫止損、時間退出、跳空、總曝險與資金占用 | 不把止損當保證最大損失 |
| 劇本 | 觸發、確認、下單、未成交、部分成交、出場與取消 | 必要條件未齊則待確認 |

技術課已知案例方法：近20日平台上緣、近3日低點、均價關係與1R。這是課堂練習，不強制套到所有事件。籌碼的特定公式待講師提供，不自行設定通用閾值。
